## ROS 2 workspace

```bash
source /opt/ros/jazzy/setup.bash
```
bygg ved å kjøre 
```bash
colcon build 
```
then source workspace 
```bash
source install/setup.bash
```
run the code

```bash
ros2 run package_name node_name
```
